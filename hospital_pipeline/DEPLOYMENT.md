# 🚀 Streamlit Deployment Guide

## Quick Start (Local)

Run the Streamlit app locally:
```bash
cd hospital_pipeline
streamlit run app.py
```

The app will automatically run the pipeline (`main.py`) on first load if data doesn't exist.

---

## 📤 Deploy to Streamlit Cloud

### Prerequisites
- GitHub account
- Your code in a GitHub repository

### Step-by-Step Deployment

#### 1. **Push Your Code to GitHub**
```bash
cd hospital_pipeline
git init
git add .
git commit -m "Initial commit for hospital data pipeline"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

#### 2. **Deploy on Streamlit Cloud**
1. Go to [share.streamlit.io](https://share.streamlit.io)
2. Sign in with your GitHub account
3. Click **"New app"**
4. Fill in the details:
   - **Repository**: `YOUR_USERNAME/YOUR_REPO_NAME`
   - **Branch**: `main`
   - **Main file path**: `hospital_pipeline/app.py`
5. Click **"Deploy!"**

#### 3. **Wait for Deployment**
- Streamlit will install dependencies from `requirements.txt`
- The app will run the pipeline automatically on first load
- Your app will be live at: `https://YOUR_APP_NAME.streamlit.app`

## 🔧 How It Works

### Integrated Pipeline Execution
The modified `app.py` now:
1. **Auto-runs pipeline** on first load if data doesn't exist
2. Provides a **"▶️ Run Pipeline" button** to manually re-run
3. Uses caching to avoid unnecessary re-runs
4. Shows progress spinner during execution

### Manual Pipeline Execution (Optional)
You can still run the pipeline separately:
```bash
python main.py
```

## 🐛 Troubleshooting

### Issue: "Pipeline failed on startup"
**Solution**: Ensure all input files (`ehr.csv`, `vitals.docx`, `labs.docx`) are in the repository

### Issue: "Module not found"
**Solution**: Check that all dependencies are listed in `requirements.txt`

### Issue: "Data not showing"
**Solution**: Click the **"▶️ Run Pipeline"** button to regenerate data

### Issue: "Streamlit Cloud deployment fails"
**Solution**: 
- Check the **Logs** in Streamlit Cloud dashboard
- Verify file paths are correct (use relative paths)
- Ensure all required files are committed to GitHub

## 🎯 Alternative Deployment Options

### Option 1: Heroku
```bash
# Create Procfile
echo "web: streamlit run app.py --server.port=$PORT" > Procfile
```

### Option 2: AWS/Azure/GCP
- Use Docker container
- Deploy as web service
- Expose port 8501

### Option 3: Local Network
```bash
streamlit run app.py --server.address=0.0.0.0
```

## 📝 Environment Variables (Optional)

If you need to configure environment-specific settings, create a `secrets.toml`:

```toml
# .streamlit/secrets.toml
[database]
host = "your-db-host"
port = 5432
```

Access in code:
```python
import streamlit as st
db_host = st.secrets["database"]["host"]
```
